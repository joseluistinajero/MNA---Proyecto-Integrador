## 📁 Estructura del Repositorio

El proyecto está organizado de la siguiente manera para facilitar el acceso a los entregables:

* 📁 **`docs/`**: Documentos del proyecto en formato PDF (Propuesta, Marco Teórico, Reporte Final).
* 📁 **`notebooks/`**: Cuadernos de Jupyter (`.ipynb`) con la exploración de datos (EDA), entrenamiento y evaluación de los modelos.
* 📁 **`data/`**: Conjuntos de datos (datasets) o muestras utilizadas para las pruebas.
* 📁 **`media/`**: Imágenes de gráficas, arquitectura del modelo y videos de demostración del sistema funcionando.
